# Training Institute Website Project Plan

## Goal

Build a modern, responsive, multi-page training institute website
inspired by the overall structure of the reference site, using original
design, code, and assets.

## Tech Stack

-   HTML5
-   Bootstrap 5.3
-   CSS3
-   JavaScript (ES6)
-   AOS
-   Swiper
-   Font Awesome

## Folder Structure

``` text
training-institute/
├── index.html
├── about.html
├── courses.html
├── course-details.html
├── gallery.html

```
